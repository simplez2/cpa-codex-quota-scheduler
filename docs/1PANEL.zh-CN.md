# 在 1Panel 更新 CPA

调度器的连续性等待需要 CPA 宿主配合。使用本仓库维护的镜像：

```text
ghcr.io/simplez2/cli-proxy-api:latest
```

在 1Panel 容器升级的“目标镜像”填写上面的完整名称，勾选强制拉取镜像。
保留现有配置、凭据、插件和状态目录挂载。当前兼容基线为 CPA
`v8.0.73-continuity`，镜像通过原生恢复、路由和隔离环境验收后才发布。
插件自身仍可通过插件商店独立更新。

官方 `eceasy/cli-proxy-api:latest` 不包含本项目的宿主连续性扩展。
如果更换镜像后插件面板显示连续性宿主未接管，需核对容器实际镜像，
不能仅凭插件“已开启”判断原请求等待恢复已经生效。

额度 429 的处理范围：

- 发送前或首个可用响应前额度受限：隔离该凭据，再选择可用凭据。
- 全池临时额度受限：在配置的期限内保持原请求连接，等待额度恢复；取消会终止等待。
- WebSocket 增量会话引用旧上游上下文时：有备用凭据则使用 1012 重放关闭，
  由客户端重新连接并携带完整上下文，随后使用可用凭据。不能把旧账号的
  `previous_response_id` 交给另一个账号继续使用。
- 已有 `response.created` 的双向流同样会检查额度错误的恢复条件；
  无备用凭据时保留真实额度错误，用户请求格式错误仍按原规则返回。
